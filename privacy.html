Política de privacidad

Esta política describe el tratamiento de datos de Collaboration Scorer, una extensión privada para Firefox mantenida por alberto-am19.

Datos consultados y finalidad

Tras la autorización del usuario, la extensión utiliza Gmail API con acceso de solo lectura para identificar la cuenta conectada y consultar identificadores, metadatos y contenido de mensajes de los hilos que procesa. También consulta elementos visibles de Gmail para mostrar la asistencia y, cuando el usuario lo pide, insertar un texto en su editor de respuesta.

Estos datos se utilizan para ayudar a revisar propuestas comerciales, mostrar resultados y preparar textos que el usuario puede editar. La extensión no envía mensajes automáticamente.

Procesamiento y conservación local

El contenido se procesa en el dispositivo. La extensión no guarda de forma persistente una copia del cuerpo ni del asunto de los correos. Conserva en el almacenamiento del navegador resultados, identificadores y huellas de los mensajes, señales derivadas, representaciones numéricas para el funcionamiento de la asistencia, correcciones del usuario y preferencias. Los resultados y las preferencias permanecen hasta que el usuario los elimina.

Los permisos temporales de acceso a Gmail se almacenan en la sesión del navegador y tienen una duración limitada. La extensión no recibe ni almacena la contraseña de Google.

Servicios externos y sincronización opcional

Las conexiones con Google permiten iniciar sesión y consultar Gmail. La extensión descarga recursos de procesamiento desde un proveedor externo; no envía a ese proveedor el contenido de los correos. Las solicitudes de red pueden revelar al proveedor datos de conexión como la dirección IP.

La sincronización con Supabase está desactivada por defecto. Si el usuario la configura y activa, se transfieren al proyecto elegido identificadores de hilos, huellas de mensajes, un identificador derivado de la cuenta, resultados, señales y explicaciones derivadas, correcciones y fechas. Estos datos pueden revelar información comercial aunque no incluyan el texto del correo. No se transfieren cuerpos, asuntos, remitentes, representaciones numéricas del contenido ni permisos de acceso a Gmail.

La subida de preferencias es una acción separada y puede incluir las direcciones de las cuentas autorizadas y el perfil comercial configurado. Las credenciales necesarias para la sincronización se conservan localmente. El alojamiento, conservación y eliminación de datos remotos dependen del proyecto de Supabase que haya configurado el usuario.

Uso limitado

Los datos de Google se usan exclusivamente para las funciones descritas y visibles para el usuario. No se venden ni se utilizan para publicidad o para entrenar modelos de inteligencia artificial de uso general. El mantenimiento de la aplicación no da al desarrollador acceso automático a los correos.

El uso y la transferencia de información recibida de las API de Google cumplirán la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.

Control, revocación y eliminación

El usuario puede retirar una cuenta de la configuración, desconectarla y revocar el acceso desde las conexiones de su cuenta de Google. En los ajustes de la extensión puede borrar los resultados y correcciones locales y la caché de recursos de procesamiento. Para eliminar también las preferencias y otros datos locales, puede desinstalar la extensión y eliminar sus datos del navegador.

Borrar datos locales o desconectar Supabase no elimina los datos remotos. Si utilizó la sincronización, el usuario debe eliminarlos en su proyecto de Supabase; de otro modo podrían descargarse de nuevo al sincronizar.

Este sitio y contacto

Estas páginas no contienen formularios de recogida de correos, analítica propia ni publicidad. GitHub Pages presta el alojamiento y puede tratar datos de conexión conforme a su política de privacidad.

Para consultas, utiliza el enlace de contacto al pie. Las consultas de GitHub son públicas: no incluyas mensajes, credenciales ni otros datos personales. Si se necesita información privada, deberá acordarse antes un canal adecuado.

Cambios

Esta política se actualizará cuando cambie el tratamiento de datos. La fecha de la versión aparece al inicio de la página.
